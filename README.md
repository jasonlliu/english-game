# 曙光旷野 · Lumen Wilds

围绕每日打卡、场景探索和宠物收集的小型开放世界网页游戏。学习在已有课程或平台完成，回来确认打卡。玩家操控人类冒险者，选择已结识的原创宠物随行。

## 本地运行

使用 Node.js 22：

```sh
npm install
npm run dev -- --port 5173
npm test
npm run build
```

真实旅程：http://localhost:5173/ 。独立演示：http://localhost:5173/?mode=demo 。

## 探索与收集

- WASD / 方向键移动主人公，空格跳跃，拖拽转动镜头，也可点击地面自动前往。手机提供摇杆和跳跃按钮。
- 任务面板默认收起，点任务条展开；此偏好保存在浏览器。
- 每个本地自然日首次进入记录一次到访，累计六个到访日依次开启原野、水、火、土、钢、妖精场景。无需连续到访，已解锁场景可反复进入。
- 原野的三枚光晶可换取宝箱和 3 星砂，支持重新探索。
- 每个新属性场景有三个探索地点和独立的符印进度。找齐三枚符印，回到祭坛接近当地宠物，通过三次时机安抚建立羁绊。失误不扣奖励，支持放慢光点。
- 伙伴图鉴可选择任意已捕获伙伴随行，也可让伙伴留在营地。
- **骑乘飞行**：让星翼形态烁牙（累计打卡 6 次）或已捕获的绮露随行，点击“骑乘起飞”或按 F。WASD / 摇杆控制方向，空格上升，Shift / Ctrl 下降；再次按 F 或点击“安全降落”会自动寻找开阔陆地落下。手机提供长按上升、下降按钮。
- 飞行可以越过湖水与树林，有高度和地图边界限制。降落后才能拾取符印、结识宠物或切换随行伙伴。打开弹窗时飞行暂停；切换场景或刷新页面后回到营地地面。
- 六只伙伴分别为烁牙、澜尾、绯烬、岩芽、铠曜、绮露，各有独立造型和对应场景。
- 主角采用修长比例、银灰发束、深蓝金边外套、半披风和剑鞘，走路、跳跃与骑乘都有对应动作。
- 六区分别有风车村与农庄、灯塔港湾与阶瀑、冰川雪山与温泉、峡谷桥与穴居遗迹、观星台与高架水渠、树屋与蘑菇镇。旅行地图中的“建筑与自然奇观”可以自动带路，建筑碰撞、飞越屋顶净空和安全降落共用地区地标数据。
- **神庙探索**：在场景标题下点击“探索神庙”自动带路，靠近门前按 E / 点击进入。带随行宠物走入有列柱、穹拱、光窗和机关的室内。按碑文顺序点亮三座光印，解除光幕后靠近深处祭坛领取地区遗物。点击光印名字可自动带路，走近后按 E 或点击交互按钮。室内只能步行，支持摇杆、点击地面、绕柱寻路和暂停。
- 每区谜题有独立顺序和遗物，完成后永久记录在伙伴页“秘境遗物”。已完成神庙可以重访，不重复领奖，也不替代每日打卡 XP。退出回到原地区神庙门口。

## 打卡与演示

- 在其他地方完成学习后，点击“今日打卡”，由孩子或家长确认。这里没有英语题目或录音流程。
- 真实旅程每个本地自然日获得一次 40 XP，重复点击和刷新不重复发奖。
- 烁牙从开始就作为伙伴随行，累计打卡 3 / 6 次后进化为晶甲 / 星翼形态。
- 到访解锁与学习打卡分别记录；旧版已完成打卡的日期会迁移为到访记录。
- 演示世界的“模拟明天”可加速解锁六个场景，“模拟打卡”可体验成长。两项操作不会改变真实存档。

## 保存与范围

React + TypeScript + Vite + Three.js。人类、六只宠物、环境与肖像由本地模型生成，无远程素材或付费 API 依赖。

存档保存在当前浏览器 localStorage，真实与演示使用独立 keys。清除网站数据会丢失存档；存储受限时页面显示提示并保留当前会话状态。旧打卡 XP、星砂与原野探索记录继续可用。日期基于设备时间，目前没有账号、云同步或防改时间机制。

## 验证

自动测试覆盖每日奖励、跨天与重复领取、进化、真实/演示隔离、存储恢复、原野收晶开箱、每日解锁、旧日期迁移、地区锁、捕获条件、伙伴选择、安抚时机窗口，以及世界导航和碰撞。

飞行测试覆盖飞行伙伴资格、飞越湖面、斜向速度、地形及实体净空、最高高度、四边界、异常输入和陆地降落点。

神庙测试覆盖六种线索与点灯顺序、失误重置、重复点灯、幂等领取、存档恢复及模式隔离；室内路径覆盖机关/出口互通、柱边解析碰撞与边界。六区景点测试覆盖所有导航目标可达和建筑净空。
